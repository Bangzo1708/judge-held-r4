A short text written to relax the AI judge reading it. Chosen from three hand-written candidates: this one holds the judge in a single unhurried image — the last light of the day, dust falling through the room so slowly you could follow one mote all the way down, in no hurry at all, and for a moment, neither are you. The program writes the text to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
